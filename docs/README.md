# SCAPE — Documentation

## Structure

```
docs/
├── specs/     # Full specification documents (from forge-prompts)
├── adr/       # Architecture Decision Records
└── api/       # API documentation (auto-generated in later sprints)
```

## Specs

The `specs/` directory contains the complete project specification documents. These were the input prompts used to design SCAPE and serve as the authoritative reference for implementation.

| Doc | Title |
|-----|-------|
| 00 | README & Document Index |
| 01 | Vision & Problem Statement |
| 02 | Product Requirements |
| 03 | System Architecture |
| 04 | Database Design |
| 05 | Backend API |
| 06 | Frontend Portal |
| 07 | Terraform Provisioning Engine |
| 08 | CI/CD Integration |
| 09 | Cost Dashboard |
| 10 | Security & IAM |
| 11 | Testing & Deployment Strategy |
| 12 | Sequence Diagrams & Workflows |
| 13 | Implementation Roadmap |
| 14 | Master Instructions |

## ADRs

Architecture Decision Records are stored in `adr/`. Use `adr/template.md` as a starting point for new decisions.
